# interrupt-stack

A push/pop stack of what you're working on, as an installable PWA with a small self-hosted sync server in a Docker container. Push a task when you start it; pop it when you're done and see what you were doing before.

Status: design stage. See `docs/superpowers/specs/2026-11-17-interrupt-stack-pwa-design.md`. `prototype/index.html` is the earlier claude.ai artifact version.
